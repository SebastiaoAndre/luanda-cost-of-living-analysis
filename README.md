# Luanda Cost of Living Analysis (2014–2024)

This project analyzes the evolution of household income and essential living costs in Luanda, Angola, between 2014 and 2024.

## Objective
To understand the growing gap between income and basic living expenses and evaluate affordability trends over time.

## Tools Used
- Python
- Pandas
- Matplotlib

## Key Insights
- Living costs increased significantly over time
- Income growth did not keep pace with expenses
- The affordability gap widened year after year
- By 2024, households struggle to cover basic needs

## Project Structure
- Data preparation and cleaning
- Cost and income analysis
- Visualization of trends
- Interpretation of results
